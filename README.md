# Super Store Sales Dashboard (Power BI)

## 📌 Project Overview
This project focuses on data visualization using Power BI. The dataset was mostly clean from the start, so the primary focus was to connect tables, build an interactive user interface, and calculate business performance metrics visually.

## 🎯 Project Objective & Problem Statement
The objective of this project is to transform store sales records into an interactive, visually appealing executive dashboard. The project solves business tracking problems through these key components:
1. **Data Modeling & DAX:** Used 2-3 essential DAX formulas to calculate key business metrics and KPIs.
2. **Dashboard Creation:** Identifying KPIs and adding interactive visualizations with filtering capabilities.
3. **Actionable Insights:** Delivering data-driven findings to support business growth and track customer satisfaction.

## 🛠️ Tools & Technologies Used
* **Power BI Desktop:** Used for data connection, DAX calculations, and visual report design.

## ⚙️ Key Features Executed
* **DAX Measures:** Written 2-3 basic DAX formulas for customized metric calculations.
* **Interactive Slicers:** Added Region-based filters (Central, South, East, West) to drill down into data instantly.
* **Visual Charts:** Used card visuals for overall metrics, Pie/Donut charts for segments, and Line/Bar charts for monthly profits.

## 📊 Key Insights From the Dashboard
* **Overall Metrics:** The store achieved total Sales of 138.83K with a Profit of 9.45K and a Profit Margin of 6.80%.
* **Payment Preference:** Online payment modes are the most popular, capturing 41.16% of total transactions, closely followed by COD at 39.39%.
* **Top Customer:** "Helen" is the highest-contributing customer to the business, bringing in 5.88K in sales.
* **Sales Segment:** The Consumer segment is the largest driver of business, contributing 47.15% to total sales.
